# EkiLink（エキリンク）

EkiLink（エキリンク）は、
駅構内の空間・設備・経路を3Dで可視化し、
**誰一人取り残さないバリアフリーナビゲーション**を提供する
駅構内ナビゲーションWebアプリケーションです。

**すべての人に、迷わない駅を。**

## 概要

EkiLinkは、階層別屋内地理空間情報データ仕様書に基づいたGeoJSONデータを使用し、駅構内の3Dネットワークを可視化するWebアプリケーションです。MapLibre GL JSとdeck.glを組み合わせることで、3D空間でのネットワーク構造、設備配置、経路探索を実現しています。

### コンセプト

**「移動弱者にとっての都会の駅は攻略不可能なダンジョンである」**

この課題に対し、EkiLinkは **誰一人取り残さないバリアフリーナビゲーション** を提供します。

- **階段・エスカレーターを回避**: 車椅子利用者や高齢者でも安心して移動できる経路を提案
- **エレベーター・スロープを優先**: バリアフリー設備を活用した最適な経路を検索
- **3D可視化による直感的な理解**: 複雑な階層構造を3Dで可視化し、誰もが迷わず、安全に移動できることを目指します

## 解決する課題

### 1. 移動弱者にとっての駅構内の困難

- 複雑な階層構造により、目的地への経路が分かりにくい
- **階段・エスカレーターが障壁**: 車椅子利用者や高齢者にとって、階段やエスカレーターは移動の障壁となる
- **バリアフリー経路の情報不足**: エレベーターやスロープの位置情報が分かりにくく、バリアフリー経路の検索機能が不足
- 緊急時の設備（AED、トイレなど）への迅速なアクセスが困難

### 2. バリアフリー情報の不足

- エレベーターやスロープの位置情報が分かりにくい
- バリアフリー経路の検索機能が不足
- 移動支援が必要な人への情報提供が不十分
- 階段・エスカレーターを回避した経路の提案ができない

### 3. 動線シミュレーションの必要性

- 駅の一部通路が閉鎖された際の動線変更を迅速にシミュレーション
- イベント時や工事時の混雑予測と動線最適化
- 災害時の避難経路の可視化

## 主な機能

### 1. 設備への最短経路検索

駅構内の特定設備（トイレ、AED、エレベーターなど）への最短経路を検索できます。

- **設備一覧からの選択**: 設備一覧から目的の設備を選択すると、自動的に到着地がセットされ、出発地を選択するだけで最短経路が表示されます
- **直感的な操作**: ノード、設備、空間をクリックするだけで経路検索が可能
- **自動経路検索**: 出発点と到着点が選択されると、自動的に最短経路が表示されます（経路検索ボタンは不要）
- **距離を考慮した経路検索**: linkデータの`distance`プロパティを優先的に使用し、実際の距離を考慮した最短経路を検索
- **経路アニメーション機能**: 検索した経路を移動するアニメーションを再生し、実際の移動をイメージできます

### 2. バリアフリー経路検索（コア機能）

**移動弱者に配慮した経路検索機能を提供します。**

- **バリアフリー検索モード**: 階段・エスカレーターを完全に回避した経路を検索
  - 車椅子利用者や高齢者でも安心して移動できる経路を提案
  - エレベーターやスロープを優先的に使用
  - 経路が見つからない場合は、通常経路を表示（警告付き）

- **通常検索モード**: エレベーターを基本的に回避（経路が見つからない場合は自動的にエレベーターを使用）
  - 階段やエスカレーターは使用可能
  - より多くの経路選択肢を提供

- **検索モードの切り替え**: トグルタブで「通常検索」と「バリアフリー検索」を簡単に切り替え可能
- **自動再検索**: 検索モードを変更すると、自動的に経路が再検索されます

### その他の機能

- **3Dネットワーク可視化**: 階層別空間や設備配置を3Dで表示し、実地図と重ね合わせて表示
- **設備一覧機能**: 階層別・カテゴリ別に設備を整理し、同じカテゴリの設備をグループ化して表示
- **インタラクティブな情報表示**: ノード、設備、空間の詳細情報をクリックで表示

## 技術スタック

### コアライブラリ

- **MapLibre GL JS 3.6.2**: 3D地図表示エンジン
- **deck.gl 8.9.33**: 3Dレイヤー描画ライブラリ（WebGL）
- **Carto Dark Matter**: OpenStreetMapデータを使用したダークテーマのベースマップ

### データ形式

- **GeoJSON**: 階層別屋内地理空間情報データ仕様書に基づいた標準形式
- **座標系**: JGD2011 / (B,L) - 世界測地系 緯度経度

### アルゴリズム

- **最短経路探索**: ダイクストラ法による最短経路探索
- **グラフ構築**: ノードとリンクデータから無向グラフを構築
- **距離計算**: linkデータの`distance`プロパティを優先的に使用し、実際の距離を考慮
- **バリアフリー経路フィルタリング**: 階段・エスカレーター・エレベーターの属性情報を活用した経路フィルタリング

## 今後の展望

### 1. バリアフリー経路検索の高度化

**「歩行空間ナビ・プロジェクト（ほこなび）」との連携**

駅構内のバリアフリー経路と街中の情報を統合し、あらゆる場所や移動ケースでのバリアフリー経路探索を可能に

- エレベーターやスロープの位置情報を統合
- 車椅子利用者向けのバリアフリー経路検索の精度向上
- 段差や階段を回避した経路の提案
- 視覚障害者向けの音声ガイダンス連携
- 点字ブロック情報の活用

### 2. 配送ロボットへの応用

近年、街中で配送ロボットの実証実験が多数行われています。EkiLinkの技術は以下の用途に活用できます：

- **配送ロボットの経路計画**: 駅構内での最適な配送経路の自動生成
- **障害物回避**: リアルタイムでの通路閉鎖情報を反映した経路再計算
- **複数ロボットの協調制御**: 複数の配送ロボットが効率的に動作するための経路最適化
- **充電ステーションへの自動帰還**: バッテリー残量に応じた最適な充電ステーションへの経路検索

### 3. リアルタイム情報の統合

- **混雑情報**: 遅延や振替輸送などのリアルタイムの状況を反映した経路検索
- **エレベーターの稼働状況**: 故障やメンテナンス中のエレベーターを回避した経路提案
- **工事情報**: 工事中の通路を自動的に回避

### 4. 多言語対応

- 英語、中国語、韓国語などへの対応
- 外国人観光客への情報提供

### 5. データの拡充

- より多くの駅への対応
- 商業施設や周辺施設との連携
- 駅間の移動経路検索

## 使用方法

### 基本的な使い方

1. [EkiLink](https://gis-challenge.vercel.app)をブラウザで開く
2. 右上のドロップダウンから駅を選択
3. マップ上で以下が可能:
   - ノード、設備、空間をクリックして情報を表示
   - 経路検索パネルから出発点・到着点を選択して経路を検索（自動実行）
   - 左上の設備一覧ボタンから設備一覧を表示

### マップ操作

- **移動**: ドラッグ
- **回転**: 右ドラッグ
- **ズーム**: マウスホイール

### バリアフリー経路検索の手順

1. **設備一覧から選択（推奨）**
   - 左上の設備一覧ボタンをクリック
   - 目的の設備（トイレ、AEDなど）を選択
   - 同じフロアで最も近いノードが到着地として自動セット
   - 「出発地点を選択してください」というトーストが表示される

2. **検索モードの選択**
   - 右下の経路検索パネルの上部で「通常検索」と「バリアフリー検索」を切り替え
   - **バリアフリー検索**: 階段・エスカレーターを回避した経路を検索（推奨）
   - **通常検索**: エレベーターを基本的に回避

3. **出発地点の選択**
   - マップ上でノード、設備、または空間をクリック
   - 出発点と到着点が両方選択されると、自動的に最短経路が表示される

4. **経路アニメーション**
   - 経路検索完了後、経路検索パネルの右上に再生ボタンが表示される
   - 再生ボタンをクリックすると、出発地点から到着地点までを移動するアニメーションが再生される

  - 階段・エスカレーターを回避した経路検索により、移動の障壁を除去
- **緊急時の迅速な対応**: AEDやトイレなど、緊急時に必要な設備への迅速なアクセス
- **災害時の避難支援**: 災害時の避難経路の可視化と最適化
- **駅の利便性向上**: 駅構内の動線最適化による混雑緩和
- **新技術への応用**: 配送ロボットなど、新技術への応用による社会インフラの高度化
- **インクルーシブデザインの実現**: すべての人が利用できる駅構内ナビゲーションの提供
